## 📌 Project Overview

**InterviewIQ** is an AI-powered placement preparation platform built for students, freshers, and job seekers.  
It brings together interview practice, RAG-based study tools, resume gap analysis, and flashcard generation in one simple workflow.

The goal of the project is to make preparation easier, faster, and more practical. Instead of switching between different apps, users can prepare in one place using AI-driven tools designed for real interview readiness.

InterviewIQ focuses on:

- Mock interview practice
- Study help from uploaded PDF notes
- Resume vs job description matching
- Flashcard generation for revision
- Clean and modern UI for a better learning experience

## 🎯 What This Platform Does

InterviewIQ helps users prepare across the full interview cycle:

1. **Practice interviews** with AI
2. **Study notes** through document-based Q&A
3. **Check resume gaps** against a job description
4. **Revise faster** using flashcards
5. **Track preparation** in a more structured way

This makes the platform useful for:
- College students
- Final-year students
- Freshers
- Job seekers
- Placement preparation

# ✨ Features

## 🎤 AI Mock Interview

A voice-based interview practice flow where users can prepare for interview rounds with AI-generated questions.

### Includes:
- HR interview practice
- Technical interview practice
- Custom job-description-based interview flow
- Question-based conversation
- Interview session handling
- Response-based interaction

### Why it matters:
This helps users practice speaking, answering clearly, and building interview confidence.

---

## 📘 Study from Notes

Users can upload PDF notes and ask questions from their own study material.

### Includes:
- PDF upload support
- RAG-based retrieval
- Context-aware answers
- Study-focused question answering
- Revision support from uploaded content
- Notes-based learning flow

### Why it matters:
Instead of reading the full PDF every time, users can directly ask questions and get helpful answers from the document.

---

## 📄 Resume Gap Finder

This feature compares a resume against a job description and identifies what is missing.

### Includes:
- Resume analysis
- Job description comparison
- Skill gap detection
- Improvement suggestions
- Better preparation guidance
- Resume-ready insights

### Why it matters:
Users can understand how well their resume matches the role and improve it before applying.

---

## 🧠 Generate Flashcards

This feature creates revision-friendly flashcards from study content.

### Includes:
- AI-generated MCQ style flashcards
- Concept revision
- Quick practice mode
- Easy memory refresh
- Better last-minute revision support

### Why it matters:
It helps users revise important points quickly and stay prepared before interviews or tests.
